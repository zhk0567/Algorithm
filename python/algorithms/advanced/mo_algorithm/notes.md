# 莫队（Mo's algorithm）

离线处理区间询问：通过调整询问顺序，使指针在数组上移动的总距离约为 O((n+q)·√n)。

## 本目录

| 文件 | 说明 |
|------|------|
| `mo_algorithm.py` | 静态数组 + 区间**不同元素个数**（`add`/`remove` 维护频数） |

## 推荐题

- 入门可搜「莫队算法 区间不同元素个数」；本仓库实现与 [区间查询专题](../../prefix_sum/notes.md)（前缀和）互补：莫队适合**难以 O(1) 拆贡献**的区间信息。
