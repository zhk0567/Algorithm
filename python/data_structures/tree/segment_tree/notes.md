# 线段树（Segment Tree）

## 简介

区间查询与单点/区间修改；本实现：**区间和查询 + 区间加懒标记**。

## 核心思想

完全二叉树结构；懒标记表示该区间待下推的加法。

## 操作与复杂度

| 操作 | 时间 |
|------|------|
| 建树 | O(n) |
| 区间加 / 区间求和 | O(log n) |

## 典型应用

RMQ、区间最值、扫描线辅助。仓库题解对照：[LC 307 区域和检索 - 可变](../../../problems/leetcode/0307_range_sum_query_mutable/)（同题亦含树状数组写法，见 `fenwick_tree`）。

## 代码要点

`push_down` 在访问子节点前传播懒标记；区间与 `[l,r]` 不交时剪枝。
