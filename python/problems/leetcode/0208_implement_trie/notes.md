# LeetCode 208 — Implement Trie (Prefix Tree)

## 题面

- **链接**：<https://leetcode.cn/problems/implement-trie-prefix-tree/>
- **简述**：实现 `insert` / `search` / `startsWith`。

## 思路

字典树：边为字符，节点标记单词结尾。

## 复杂度

单次操作 O(L)，L 为字符串长度。
