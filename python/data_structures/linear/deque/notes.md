# 双端队列（Deque）

## 简介

两端 O(1) 插入删除。本实现为**循环数组双端队列**（不依赖语言内置 deque）。

## 核心思想

维护 `front` 与 `size`，逻辑索引对 `cap` 取模；容量不足时扩容并紧凑排列到从 0 开始。

## 操作与复杂度

| 操作 | 平均 | 最坏 |
|------|------|------|
| `push_front` / `push_back` / `pop_*` | O(1) 摊还 | O(n) 扩容时 |

## 典型应用

单调队列、滑动窗口最大值、BFS 0-1 边。

## 代码要点

`front` 前移用 `(front - 1 + cap) % cap`；扩容后 `front = 0`。
