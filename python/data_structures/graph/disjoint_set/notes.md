# 并查集（Disjoint Set / Union-Find）

## 简介

维护不相交集合，`find` 与 `union`；路径压缩 + 按秩合并接近 O(α(n))。

## 核心思想

- **按秩合并**：小树挂大树，控制树高。
- **按大小合并**：把 `size` 小的根连到大的根上（与秩类似，见代码注释）。
- **路径压缩**：查找时把节点直接连到根。

## 操作与复杂度

| 操作 | 均摊 |
|------|------|
| `find` / `unite` | O(α(n)) |

## 典型应用

Kruskal、连通块、离线询问。

## 代码要点

`unite` 时若已在同一集合返回 `false`。
