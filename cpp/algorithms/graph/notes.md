# 图算法（C++）

| 子目录 | 内容 | 入口 |
|--------|------|------|
| `traversal/` | DFS、BFS | `graph_traversal.cpp` |
| `shortest_path/` | Dijkstra、Bellman–Ford、Floyd–Warshall | `dijkstra.cpp`、`bellman_ford.cpp`、`floyd_warshall.cpp` |
| `mst/` | Kruskal、Prim | `kruskal.cpp`、`prim.cpp` |
| `topological_sort/` | 拓扑排序 | `kahn.cpp` |
| `scc/` | Tarjan | `tarjan.cpp` |
| `network_flow/` | 最大流 | `edmonds_karp.cpp` |
| `bipartite_matching/` | 二分图最大匹配（Kuhn）、最小费用完美匹配（匈牙利 KM） | `bipartite_matching.cpp` |
| `lca/` | 树上倍增 LCA | `lca.cpp` |
