# 动态数组（Dynamic Array / ArrayList）

## 简介

在内存中连续存储元素，容量不足时按策略扩容（通常 2 倍），对外表现为可变长数组。适合随机访问多、尾部增删多的场景。

## 核心思想

- 维护 `size` 与 `capacity`；`size == capacity` 时分配更大缓冲区并搬移元素。
- 摊还分析：`push_back` 均摊 O(1)。

## 操作与复杂度

| 操作 | 平均 | 最坏 | 说明 |
|------|------|------|------|
| `at` / 下标访问 | O(1) | O(1) | |
| `push_back` | O(1) 摊还 | O(n) | 扩容时 O(n) |
| `pop_back` | O(1) | O(1) | 可选缩容策略 |
| `insert` / `erase` 中间 | O(n) | O(n) | 需搬移 |

空间：O(n)。

## 典型应用

- 向量、缓冲区、动态表
- 作为栈、队列的底层存储

## 代码要点

- 插入/删除注意边界与 `size` 更新。
- Python 实现用 list 作底层存储但显式维护 `capacity` 与扩容逻辑，便于理解 C 级行为。
