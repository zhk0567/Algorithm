# 队列（Queue）

## 简介

先进先出（FIFO）。循环数组避免链表队尾指针；双栈队列均摊 O(1)。

## 核心思想

- **循环数组**：`front`、`size` 或 `(front+size)%cap`。
- **两栈**：`in` 入队，`out` 出队时若空则倒 `in`。

## 操作与复杂度

| 实现 | `enqueue` | `dequeue` |
|------|-------------|-----------|
| 循环数组 | O(1) | O(1) |
| 双栈 | O(1) 摊还 | O(1) 摊还 |

## 典型应用

BFS、滑动窗口、生产者消费者。

## 代码要点

循环队列区分满与空：多留一个槽位或维护 `size`。
