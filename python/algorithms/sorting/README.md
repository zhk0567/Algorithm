# 排序（Sorting）

## 简介

将序列按关键字单调排列；不同算法在时间、空间、稳定性上不同。

## 核心思想

| 算法 | 思想概要 | 稳定 |
|------|----------|------|
| 冒泡 / 选择 / 插入 | 相邻比较或逐位插入 | 冒泡、插入稳定 |
| 归并 | 分治合并有序段 | 是 |
| 快排 | 枢轴划分 | 否（实现相关） |
| 堆排 | 大根堆不断 pop | 否 |
| 计数 / 基数 / 桶 | 利用键分布或位数 | 基数、桶可稳定 |

## 操作与复杂度

| 算法 | 最坏时间 | 平均 | 额外空间 |
|------|----------|------|----------|
| 冒泡 | O(n²) | O(n²) | O(1) |
| 选择 | O(n²) | O(n²) | O(1) |
| 插入 | O(n²) | O(n²) | O(1) |
| 归并 | O(n log n) | O(n log n) | O(n) |
| 快排 | O(n²) | O(n log n) | O(log n) 栈 |
| 堆排 | O(n log n) | O(n log n) | O(1) |
| 计数 | O(n+k) | O(n+k) | O(k) |
| 基数 | O(d(n+r)) | 同上 | O(n+r) |
| 桶 | O(n²) 桶内插排 | 近 O(n) | O(n) |

## 典型应用

通用排序、去重前排序、TopK 与堆结合。

## 代码要点

见 `sorting.py`：`merge_sort` 返回新列表；`quick_sort` 原地 Lomuto 变体；计数排序假设非负且范围适中。
