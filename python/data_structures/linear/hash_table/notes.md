# 哈希表（链地址法）

## 简介

键值映射；本实现为 **separate chaining**（拉链法），负载因子超阈值则再散列。

## 核心思想

- `hash(key) % bucket_count` 定位桶；桶内链表解决冲突。
- **开放寻址法**（线性探测、二次探测）省指针但删除麻烦、聚集敏感；拉链法实现直观。

## 操作与复杂度

| 操作 | 平均 | 最坏 |
|------|------|------|
| `insert` / `get` / `erase` | O(1) | O(n) 全冲突 |

空间：O(n + buckets)。

## 典型应用

字典、去重、计数、并查集辅助。

## 代码要点

- 负载因子 0.75 触发 `rehash`；扩容取质数或 2 幂均可，此处 2 倍桶数。
- `hash` 需对 `None` 键做约定（本示例仅 `int` 键）。
