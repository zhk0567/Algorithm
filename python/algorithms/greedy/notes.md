# 贪心（Greedy）

## 简介

每步做局部最优选择，期望得到全局最优；需证明交换论证或拟阵结构。

## 示例

- **活动选择**：按结束时间排序，贪心选取不重叠区间。
- **分数背包**：按性价比排序依次装入。

## 复杂度

排序 O(n log n) + 线性扫描 O(n)。

## 边界与反例

- `fractional_knapsack` 忽略 `weight≤0` 的物品；空列表或 `capacity=0` 返回 `0`。
- **0-1 背包**不能用分数贪心（如物品 `(1,10),(2,20),(3,30)` 容量 5，贪心 50 vs 最优 50 需按题设；经典反例：硬币 `[1,3,4]` 凑 6，贪心 4+1+1 用 3 枚，最优 3+3 用 2 枚）。
