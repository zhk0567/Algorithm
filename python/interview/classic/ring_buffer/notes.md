# 环形缓冲区（Ring Buffer）

定长数组 + 头尾下标，**队尾入队、队头出队**，下标对容量取模。满时 `push` 抛 `BufferError`、空时 `pop` 抛 `BufferError`。

## 复杂度

- `push` / `pop`：均摊 O(1)
- 空间 O(capacity)

## 面试要点

- **适用场景**：日志缓冲、网络包队列、嵌入式定长队列；SPSC 可进一步做无锁优化。
- **复杂度**：`push`/`pop` O(1)；空间 O(capacity)。
- **LeetCode**：无直接原题；与「循环数组 / 队列」类题（如设计题）口述可类比。
- **常见坑**：空满判定（`size` vs 浪费一格 vs 镜像下标）、单线程 API 误用于多线程、满/空未区分异常类型。
