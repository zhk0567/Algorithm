# 图算法（Python）

| 子目录 | 内容 | 入口 |
|--------|------|------|
| `traversal/` | DFS、BFS | `graph_traversal.py` |
| `shortest_path/` | Dijkstra、Bellman–Ford、Floyd–Warshall | `dijkstra.py`、`bellman_ford.py`、`floyd_warshall.py` |
| `mst/` | Kruskal、Prim | `kruskal.py`、`prim.py` |
| `topological_sort/` | 拓扑排序 | `kahn.py` |
| `scc/` | Tarjan、Kosaraju | `tarjan.py` |
| `network_flow/` | 最大流 | `edmonds_karp.py` |
| `bipartite_matching/` | 二分图最大匹配（Kuhn）、最小费用完美匹配（匈牙利 KM） | `bipartite_matching.py` |
| `lca/` | 树上倍增 LCA | `lca.py` |
