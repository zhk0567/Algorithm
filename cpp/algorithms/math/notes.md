# 数学相关算法（C++）

| 子目录 | 内容 | 入口 |
|--------|------|------|
| `number_theory/` | GCD、埃氏筛 | `number_theory.cpp` |
| `fast_power/` | 快速幂、模幂 | `fast_power.cpp` |
| `extended_gcd/` | 扩展欧几里得、模逆、线性同余 | `extended_gcd.cpp` |
| `combinatorics/` | 二项式系数 mod 质数 | `combinatorics.cpp` |
| `matrix/` | 矩阵乘、矩阵快速幂（斐波那契） | `matrix.cpp` |
| `geometry/` | 向量叉积、方向判定 | `geometry.cpp` |
| `probability/` | 几何分布期望 | `probability.cpp` |
