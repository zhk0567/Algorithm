# 限流器：令牌桶

> 平滑限流：每秒以 `rate` 速率往桶里放令牌，桶满则丢弃；请求来时取走 `n` 个令牌，不够则等待或拒绝。  
> 优点：允许短时突发，长期速率受限；常用于 API 限速、消息队列削峰。

## 关键点

- **延迟生成**：不开后台线程定时补令牌，**每次请求时按时间差计算** 应补多少令牌，避免精度与线程开销。
- `tokens = min(capacity, tokens + (now - last) * rate)`
- 用 `time.monotonic()` 防止系统时间回拨。
- 用一把 `Lock` 串行化并发访问。

## API

- `try_acquire(n=1)`：拿不到立刻返回 `False`
- `acquire(n=1, timeout=None)`：阻塞等待至获得或超时

## 自测

`rate_limiter.py` 用 5 token/s 的桶在 1.05 秒内尝试拿 ~12 次，校验通过数大致在 (容量, 容量+速率·t) 范围内。
