# 时间 / 空间复杂度速查

| 记号 | 含义 |
|------|------|
| O(1) | 常数 |
| O(log n) | 对数（二分、平衡树高度） |
| O(n) | 线性 |
| O(n log n) | 常见高效排序、分治 |
| O(n²) | 朴素双重循环 |
| O(2ⁿ) / O(n!) | 指数 / 阶乘（慎用，多为剪枝回溯） |

## 常见操作

| 结构 / 操作 | 平均时间 | 最坏时间 | 空间 |
|---------------|----------|----------|------|
| 数组随机访问 | O(1) | O(1) | — |
| 哈希表插入/查找 | O(1) | O(n) | O(n) |
| 平衡 BST 插入/查找 | O(log n) | O(log n) | O(n) |
| 堆 push/pop | O(log n) | O(log n) | O(n) |
| 排序（比较） | O(n log n) | O(n log n) | O(1)~O(n) |
| DFS/BFS（图） | O(V+E) | O(V+E) | O(V) |
| Dijkstra（非负权） | O((V+E) log V)（堆） | 同上 | O(V) |

## 分析习惯

- 数 **状态规模**（DP 维度）、**分支因子**（回溯）、**单调栈维护** 的摊还。
- 空间勿忘 **递归栈** 与 **辅助数组/哈希表**。
