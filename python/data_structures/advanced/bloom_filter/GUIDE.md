# 布隆过滤器（Bloom Filter）

## 简介

概率型数据结构：只增不删（或需计数布隆）；**可能误判存在**（false positive），不会误判不存在。

## 核心思想

m 位 bit 数组 + k 个独立哈希；插入时将 k 个位置置 1；查询看是否全为 1。

## 操作与复杂度

| 操作 | 时间 |
|------|------|
| `add` / `possibly_contains` | O(k) |

空间 O(m)；最优 k ≈ (m/n) ln 2（n 为元素数）。

## 典型应用

爬虫 URL 去重、数据库避免磁盘查找、缓存穿透防护。

## 代码要点

Python 用 `bytearray` 存位；C++ 用 `vector<uint64_t>` 字寻址。哈希为教学用简单多项式哈希族。
