# LeetCode 75 — Sort Colors（颜色分类）

## 题面

- **来源**：LeetCode 75
- **链接**：<https://leetcode.cn/problems/sort-colors/>
- **简述**：原地把仅含 `0,1,2` 的数组排序。

## 思路

**荷兰国旗三指针**：`l` 指向下一个 0 落点，`r` 指向下一个 2 落点；`i` 扫描，遇 0 与 `l` 交换并 `l,i+=1`；遇 2 与 `r` 交换并 `r-=1`（`i` 不前进）；遇 1 `i+=1`。

## 复杂度

时间 O(n)，空间 O(1)。
