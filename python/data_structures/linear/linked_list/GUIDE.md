# 链表（单链表 / 双链表）

## 简介

通过指针（引用）串联节点，非连续存储；插入删除 O(1) 定位到节点后，但查找需 O(n)。

## 核心思想

- **单链表**：每个节点 `next`。
- **双链表**：`prev` + `next`，删除与在节点前插入更方便。

## 操作与复杂度

| 操作 | 已知节点 | 需查找 |
|------|----------|--------|
| 头尾插入/删除 | O(1) | O(1) 若有哑头尾 |
| 按值查找 | — | O(n) |
| 反转 | O(n) | — |

空间：O(n)。

## 典型应用

LRU 双向链表、多项式、大块内存分配器空闲链表。

## 代码要点

- 哨兵节点（dummy）简化头插。
- 双链表删除注意更新前后邻居。
